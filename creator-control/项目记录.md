## 1. 关键技术方案（务必先读，避免重复踩坑）

### 1.1 滴答清单 API（Dida365 Open API）
- Base：`https://api.dida365.com/open/v1/...`，OAuth2 Bearer Token 鉴权。
- **🔴 重大发现（已验证）**：
  - `GET /project` 返回的是**纯 JSON 数组** `[{id,name,sortOrder,...}]`，**不是** `{projects:[...]}`。
  - 每个 project 对象里**没有 `tasks` 字段**。必须对每个项目再调 `GET /project/{id}/data` 才能拿到 `{tasks:[...]}`。
  - 任务字段：`title`、`status`（0=未完成 / 1=已完成）、`dueDate`（ISO `"2027-06-19T01:00:00.000+0000"`）、`startDate`、`isAllDay`。
- **🔴 浏览器直连（didaFetch）**：滴答 API 必须由**用户浏览器直接 fetch**，**不要走 Vercel 海外代理**。原因：用户在中国大陆，Vercel 服务器（海外）→ 中国大陆 API 会超时。函数 `didaFetch(url,opts)` 就是裸 `fetch`（不走 `/api/cors`）。
- 相关函数：`didaGet()`（拉全部任务，逐项目拉取）、`didaComplete(id,done)`（标记完成同步）、诊断页 `dida-diag.html`。

### 1.2 Notion API
- 版本 `2022-06-28`，Integration Token（格式 `secret_...` 或 `ntn_...`），`POST /v1/databases/{id}/query`。
- Notion 调用**走代理** `/api/cors?url=`（CORS 限制），函数 `proxyFetch` / `notionQuery` / `notionCreate`。
- 字段映射见 §4。

### 1.3 凭证安全
- 所有 Token **只存用户浏览器 localStorage（`wb-config-v1`）**，不进代码、不进 GitHub。
- 用户曾担心 Token 泄漏；结论：聊天里出现过 Token 没关系，因为**只存在 localStorage + 私人对话**，不在代码仓库，无需反复 regenerate。

### 1.4 GitHub 推送阻塞（待解决）
- 沙箱环境到 `github.com` 的 TLS 握手被掐断：`gnutls_handshake() failed: The TLS connection was non-properly terminated`。
- 这是**沙箱网络出口限制**，与代码/账号无关。**已本地提交 4 个 commit 领先 origin，无法 push**。
- 临时查看 App 用沙箱预览链接（见 §6），不依赖 GitHub。

## 3. 各页面当前状态（2026-07-29 Round G 后）

### 主页（view-home）
- 顺序：**语录卡（紫渐变）→ 目标（白卡）→ 今日三事（粉卡）**。
- **目标**：**只显示标题**（无长/短期目标 tag、无日期），长期目标在前，**周核心（短期）仅展示当前周一~周日范围内的内容**。无勾选框。
- **今日三事**：前 3 件**当天**待办 + **本周内**提醒，合并展示。普通任务带「重要」粉色徽章，提醒型带「提醒」黄色徽章 + 黄左边框。*提醒已过滤为仅本周内，过期不显示。*

### 时间与事件（view-time）— 三个 Tab
1. **📋 待办**：**仅显示当天**的任务按生活领域分组；**提醒保留近一周内**；目标型不在此（已在首页）。*非当天的普通待办不出现。*
2. **⏱️ 时间账本**：**接入滴答专注记录 API**（`didaFocus()` 拉取本周 `focus/time/get`），按时长（分钟）聚合到各清单/项目 → **SVG 环形饼图（占比%）+ 柱状图（%）+ 图例（时长 h/m）+ 标签筛选**（全部/创作/输入/运营/生活）。中心显示"本周专注 X.Xh"。无配置时回退 sample 数据。
3. **🔄 习惯**：**本月视图改为展示全月日期（1..dim）+ 缩小方块尺寸**（`.hc-grid.month` max-width:224px, cell aspect-ratio:1, font-size:8px, 显示日期数字）；本周视图保持 7 格。每个习惯独立卡片含连续天数 + 完成率%。

## 5. 任务分类逻辑（renderHomeFromTasks / taskType）
- **目标型**：项目名/标题含「周核心/短期目标/本周」→ 短期；含「新阶段目标/阶段目标/长期目标」→ 长期。无勾选框。**渲染时只显示标题（无 badge/tag/日期），周核心仅显示 dueDate 落在当前周一~周日范围内的。**
- **提醒型**：项目名 ==「保险」，或标题含 到期/续费/缴费/续约/预约/体检/年检 → 橙色，可勾选。**首页今日三事中提醒仅保留本周内（withinLastWeek）。**
- **可执行**：其余。`⚠️ 曾踩坑：提醒型正则误写成 /(^|保险)/，^ 导致所有任务被判为提醒，已修复为 t.project==="保险" 判断。`

### 5.1 新增辅助函数（Round G）
- `thisWeekRange()` → 返回当前周一 00:00 ~ 周日 23:59
- `inThisWeek(iso)` → ISO 日期是否在本周（无日期视为 true）
- `withinLastWeek(iso)` → 是否在过去 7 天内（含今天）
- `isTodayISO(iso)` → 是否为今天
- `didaFocus()` → 拉取滴答专注记录 `/open/v1/focus/time/get?startDate=...&endDate=...`，按 listName 聚合分钟数返回 `[{n,mins}]`
- `parseScore(s)` → 从 Notion 质感文本提取数字分数
- `daysInYearSoFar()` / `renderMoodSummary(count)` → 今年记录天数统计
