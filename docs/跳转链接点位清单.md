# 跳转链接点位清单（Jump Link Map）

> 用途：清晰标注工作台内 **每一个跳转动作** 的目标工具、页面与参数。
> 规则：所有「编辑 / 新建 / 明细 / 深度写作」均跳转外部网页视图，工作台内只做只读浏览与单行灵感录入。
> 占位链接需替换为你的真实 workspace ID（见文末「配置模板」）。

## 七、跳转链接配置模板（填入真实 ID 即上线）

```javascript
// index.html 顶部 LINKS 配置（替换占位 ID）
const LINKS = {
  dida:{
    today: "https://dida365.com/webapp/#/today",
    goal:  "https://dida365.com/webapp/#/goal",
    habit: "https://dida365.com/webapp/#/habit",
    timer: "https://dida365.com/webapp/#/statistic",
  },
  notion:{
    intake:    "https://www.notion.so/<你的工作区>/<信息摄入库-ID>",
    idea:      "https://www.notion.so/<你的工作区>/<灵感库-ID>",
    diary:     "https://www.notion.so/<你的工作区>/<日记模板-ID>",
    project:   "https://www.notion.so/<你的工作区>/<项目进度库-ID>",
    breakdown: "https://www.notion.so/<你的工作区>/<爆款拆解库-ID>",
    kb:        "https://www.notion.so/<你的工作区>/<AI知识库-ID>",
  }
};
```

### 链接键速查表

| 链接键 | 目标工具 | 页面含义 |
|--------|----------|----------|
| `dida.today` | 滴答清单 | 今日清单 |
| `dida.goal` | 滴答清单 | 目标 |
| `dida.habit` | 滴答清单 | 习惯打卡 |
| `dida.timer` | 滴答清单 | 时间统计 |
| `notion.intake` | Notion | 信息摄入库 |
| `notion.idea` | Notion | 灵感库 |
| `notion.diary` | Notion | 日记模板 |
| `notion.project` | Notion | 项目进度库（含正在进行 / 发布复盘） |
| `notion.breakdown` | Notion | 爆款拆解库 |
| `notion.kb` | Notion | AI 应用知识库 |

> 约定：在真实部署中，点击跳转统一使用 `window.open(url, "_blank")`；演示版为避免打开占位链接，仅弹出「即将跳转」提示并在控制台打印目标 URL。

## 八、v2 版本关键变更（对照 v1）

> 以下变更已落实到 `index.html`，本文档据此更新行为说明。

| 项 | v1 | v2 |
|----|----|----|
| **G5 计时器** | 内置倒计时弹窗（有常驻不消失 bug） | 直接 `jump('dida','timer')` 跳转滴答计时，**已移除弹窗** |
| **Notion 类跳转** | 跳转固定占位 URL | 按配置在设置中填入的数据库 ID，直接 `open('https://www.notion.so/<ID>')` 打开对应库；未配置则提示并弹出设置 |
| **数据来源** | 全部 mock 写死 | 清空 mock；未配置显示「前往配置」空状态；设置含「示例数据」开关仅用于预览布局 |
| **灵感中枢** | 三区块纵向堆叠 | 顶部三个 Tab：**信息摄入·Newsletter / 灵光一现 / 日记**（无需下拉） |
| **信息摄入扒取** | 仅导入框触发演示 | 新增小红书/GitHub 平台切换 + AI 自动打 `AI/内容` 类标签，聚合为专属 Newsletter，并反向写入 Notion 信息摄入库 |
| **今日事件** | 仅展示 | 单击=标记完成（同步滴答）；长按=跳转滴答计时 |
| **习惯/时间视图** | 仅展示 | 热力图单元格、标签占比行均可点击跳转对应滴答页面 |
| **发布复盘** | 仅卡片 | 点击卡片 → 打开**内容展示详情页**（播放/点赞/收藏/评论条形 + 复盘笔记） |
| **学以致用** | 仅预览 | 拆解卡片新增「⇄ 反向同步回 Notion」按钮，调用 Notion API 写入爆款拆解库 |
| **配置入口** | 无 | 顶栏 ⚙️ 打开设置：Notion Token、代理(解决CORS)、6 个数据库 ID、滴答 Token、字段名映射、示例开关 |
