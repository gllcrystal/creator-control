# 跨平台自动化流转规则（Automation Rules）

> 核心原则：**工作台负责「调度与监听」，所有数据变更最终落地 Notion / 滴答，不在 WorkBuddy 内维护业务条目。**
> 所有写操作只发生在外部工具；工作台内的写动作仅限「灵感单行录入」与「番茄计时发起」，且都回写外部。

---

## 一、数据主权与流向总览

```
        ┌─────────────── 写入方 ───────────────┐
        │                                        │
   [Notion 网页]  ←── 长篇编辑 / 项目管理 / 日记    │
   [滴答网页]    ←── 任务 / 目标 / 习惯 / 计时      │
        │                                        │
        └─────────────── 只读拉取 ──────────────┘
                         │
                 [连接器 API / Webhook]
                         │
                 [WorkBuddy 只读看板]
                         │
        ┌──────── 监听触发（自动化）────────┐
        │ 灵感状态=脚本 → 同步项目库          │
        │ 每周日 cron → AI 复盘 → 回写 Notion │
        └───────────────────────────────────┘
```

**单事实来源（SSOT）：** Notion 与滴答分别是内容与时间的唯一权威库；工作台缓存仅为渲染快照，过期即弃。

---

## 二、规则清单

### 规则 A：灵感状态机 → 自动同步项目库（强制）
- **触发条件**：监听到 Notion「灵感库」中某条目的 `状态` 字段被修改为 **【脚本】**。
- **动作**：将该条目（标题、标签、创建时间、原始链接）自动复制到 Notion「项目进度-正在进行」库，并初始化项目阶段 = 脚本。
- **方向**：灵感库 → 项目库（单向同步，仅当转「脚本」时）。
- **去重**：以灵感唯一 ID 为键，避免重复写入；若已同步则跳过。
- **回写**：在项目库条目 `来源灵感` 属性回填灵感库链接，保证可追溯。
- **实现**：Notion 官方 Automation（Database Automation）或 n8n/Make 监听 webhook。

### 规则 B：每周 AI 复盘工作流（定时调度）
- **触发**：每周固定时间（默认 **周日 21:00**，可配置）由 WorkBuddy 定时任务 / 外部 cron 触发。
- **汇总输入**：本周滴答时间记录 + Notion 日记 + 灵感记录 + 项目复盘数据。
- **处理**：调用 AI（固定提示词见《每周 AI 复盘固定提示词》）生成
  ① 个人状态复盘 ② 自媒体优化建议 ③ 下周行动计划。
- **落库**：复盘文档自动写入 Notion「复盘库」（含本周日期范围标题）。
- **记忆更新**：将结构化要点提炼进「AI 长期记忆库」，供长期复盘对话空间持续读取。
- **通知**：完成后推送一条摘要到工作台 / 滴答提醒（可选）。

### 规则 C：底部快捷栏灵感录入 → 写 Notion（即时）
- **触发**：用户在底部栏 ⚡ 录入单行灵感并提交。
- **动作**：调用 Notion API 写入「灵感库」，字段：`标题`=录入文本、`状态`=初步想法、`创建时间`=now、`来源`=中控台快捷栏。
- **约束**：工作台**不留存副本**；仅展示「已同步」反馈。
- **失败兜底**：若写入失败，提示重试，不存储于本地数据库。

### 规则 D：番茄计时 → 回写滴答（即时）
- **触发**：用户在底部栏 ⏲️ 发起/完成番茄计时。
- **动作**：计时开始/结束事件回写滴答时间统计（或对应任务计时）。
- **约束**：工作台仅发起与展示，计时数据归属滴答。

### 规则 E：信息摄入 / 爆款拆解导入（AI 提取后落库）
- **触发**：用户粘贴 GitHub / 小红书 / 短视频链接并点击「导入并分析 / 拆解」。
- **动作**：AI 提取关键词、标注重要等级 / 拆解结构 → 结果写入 Notion「信息摄入库」或「爆款拆解库」。
- **约束**：工作台不存储链接原文与长文本，仅展示摘要卡片（读取自 Notion）。

### 规则 F：数据看板刷新（只读轮询）
- **触发**：看板加载 / 定时（30–60s）或 webhook 推送。
- **动作**：连接器只读拉取滴答 / Notion 最新数据重渲染。
- **约束**：纯只读，任何刷新都不产生写操作。

## 三、连接器监听与调度机制

| 机制 | 适用 | 推荐工具 | 备注 |
|------|------|----------|------|
| **Webhook 监听** | Notion 字段变更（规则 A）、新增条目 | Notion Automation / n8n | 近实时，优先用于状态同步 |
| **定时 Cron** | 每周复盘（规则 B）、看板刷新（规则 F） | WorkBuddy 定时任务 / 系统 cron | 稳定可控 |
| **API 主动写** | 灵感录入（C）、计时回写（D）、导入落库（E） | Notion API / 滴答 API | 用户动作触发 |
| **API 只读拉取** | 所有看板渲染 | 连接器封装 | 单向只读 |

### 鉴权与安全
- Token 存环境变量 / 密钥管理服务，**绝不** 落前端、不落工作台数据库。
- 滴答连接器以只读为主；写仅限计时回写。
- Notion 写操作限定范围：灵感库写入、项目库同步、复盘库写入、知识库（按需）。

---

## 四、状态字段约定（Notion 灵感库）

| 状态值 | 含义 | 是否触发同步 |
|--------|------|--------------|
| 初步想法 | 刚记录 | 否 |
| **脚本** | 进入创作准备 | **是 → 同步至项目进度-正在进行** |
| 视频 | 拍摄/剪辑中 | 否（已在项目库） |
| 发布 | 已上线 | 否 |
| 复盘 | 已复盘 | 否 |

> 一旦转「脚本」，即视为项目立项；项目库阶段字段随后由用户在 Notion 自行推进（视频/发布/复盘）。

## 五、落地检查清单（上线前验证）
- [ ] Notion 六个数据库已建（灵感 / 日记 / 项目进度 / 信息摄入 / 爆款拆解 / 知识库 + 复盘库 + 长期记忆库）
- [ ] 滴答 API Token 配置，今日/目标/习惯/时间统计可读
- [ ] 规则 A 监听生效：灵感转「脚本」→ 项目库出现对应条目
- [ ] 规则 B 每周 cron 跑通：复盘文档出现在 Notion 复盘库，记忆库更新
- [ ] 规则 C 快捷栏录入实时出现在 Notion 灵感库
- [ ] 规则 F 看板刷新为只读，无意外写操作
- [ ] `LINKS` 映射全部替换为真实 ID，跳转验证通过
