# 自媒体创作者专属中控工作台 · 页面架构文档

> 定位：**全局中控仪表盘 + 统一导航网关**
> 形态：只读聚合外部数据（滴答清单 / Notion）+ 统一跳转外部编辑工具
> 原则：**工作台不存储长篇创作内容、不维护业务条目、不内置长篇富文本编辑器**

---

## 一、产品定位与核心理念

| 维度 | 说明 |
|------|------|
| 目标用户 | 裸辞自由职业自媒体创作者（个人） |
| 核心痛点 | ① 工具分散（滴答管时间、Notion 管内容）② AI 对话无法自动获取长期个人背景，每次重复粘贴 ③ 灵感 / 项目 / 时间缺少一站式总览 |
| 工作台角色 | **网关（Gateway）**，不是数据库。所有高价值持久化数据留在成熟工具，工作台只做「拉取 → 只读渲染 → 跳转编辑」 |
| 价值主张 | 一屏总览 + 一键直达 + AI 长期记忆，消除重复背景粘贴 |

### 三层架构（硬约束映射）

```
┌─────────────────────────────────────────────┐
│  表现层（WorkBuddy 工作台）                    │  ← 只读聚合视图 + 跳转网关 + 轻量灵感的单行录入
│  · 仪表盘 / 概览卡片 / 数据汇总（只读）          │
│  · 底部快捷栏（极简单行灵感录入 → 同步 Notion）   │
│  · AI 长期复盘对话空间（读取 + 生成，不改业务库） │
├─────────────────────────────────────────────┤
│  连接层（只读连接器）                           │  ← 连接器：API / Webhook / 定时轮询，单向只读拉取
│  · 滴答清单连接器（任务 / 时间 / 番茄计时）       │
│  · Notion 连接器（灵感 / 日记 / 项目 / 拆解 / KB）│
├─────────────────────────────────────────────┤
│  数据层（外部成熟工具 · 永久存储）               │  ← 唯一事实来源（Single Source of Truth）
│  · 滴答清单：任务、时间记录、番茄计时、习惯打卡   │
│  · Notion：灵感库、日记、自媒体项目、爆款拆解、知识库 │
└─────────────────────────────────────────────┘
```

**硬性约束落点（最高优先级，全程遵守）：**

1. 高价值持久化原始数据 **永久存储** 于滴答 / Notion，工作台禁止独立完整数据库、不长期存储长篇内容。
2. 所有统计看板 / 概览卡片 / 汇总视图 = 连接器 **只读拉取** 渲染，仅浏览。
3. 所有长篇内容深度编辑按钮 = 直接跳转对应 Notion / 滴答网页视图，**不内置富文本编辑器**用于长篇写作。
4. 仅底部常驻快捷栏支持 **极简单行** 轻量化录入碎片化灵感；录入自动同步写入 Notion 灵感库，工作台不留副本。
5. 跨平台自动化流转由工作台 **调度监听**，所有数据变更最终落地 Notion，不在 WorkBuddy 内维护业务条目。

## 二、信息架构（导航层级 ≤ 3 级）

> 规范要求：页面层级最多 3 级，杜绝过度嵌套折叠菜单。本方案采用 **一级导航（左侧常驻）+ 页内分栏（tabs）** 的两级结构，子模块以内部分栏呈现，不嵌套下拉菜单。

```
工作台（总）
├─ 1. 主页 · 全局仪表盘            [一级直达]
│     ├─ 顶部轮询：每日激励（毛选名言轮换）
│     ├─ 今日核心：今日最重要三件事（滴答高优先级聚合）
│     ├─ 进度可视化：周 / 月 / 长期目标进度
│     └─ 能量概览：当日时间分配（滴答计时）
│
├─ 2. 时间与事件管理              [一级直达]
│     ├─ 分栏① 今日事件概览（滴答当日任务 + 标签色 + 打卡态）
│     ├─ 分栏② 习惯 & 事件视图（热力图 + 标签耗时占比）
│     └─ 分栏③ 时间视图（日/周/月时间分配看板）
│
├─ 3. 灵感收集中枢                [一级直达]
│     ├─ 信息摄入概览（素材库摘要 + GitHub/小红书导入 + AI 提取）
│     ├─ 灵光一现概览（灵感清单 + 状态机 + 自动化同步）
│     └─ 每日日记概览（日历 + 文本预览）
│
├─ 4. 自媒体项目进度              [一级直达]
│     ├─ 分栏① 正在进行（脚本阶段及之后预览）
│     └─ 分栏② 发布复盘（播放/点赞/收藏/评论预览）
│
└─ 5. 学以致用                    [一级直达]
      ├─ 爆款拆解预览（链接导入 + AI 分析）
      └─ AI 应用知识库预览（知识点 + 实践案例）
```

**全局常驻组件（不计入页面层级）：**
- 顶部栏：页面标题 / 连接状态（滴答·已连接 / Notion·已连接）/ 深浅色切换
- 底部快捷栏（PC + 移动永久显示）：⚡灵光一现 / 📝新建日记 / ⏲️计时器 / 🤖唤起 AI

## 三、各页面详细设计

### 1. 主页 · 全局仪表盘
| 区块 | 数据来源 | 渲染方式 | 交互规则 |
|------|----------|----------|----------|
| 每日激励 | 本地轮换文案库（毛选名言） | 轮播卡片（8s 自动切换） | 纯展示 |
| 今日最重要三件事 | 滴答「高优先级」任务 | 3 张任务卡（勾选态/标签） | **只读**；修改/排序 → 跳转滴答今日清单 |
| 周/月/长期目标进度 | 滴答目标数据 | 进度条（数值 + 百分比） | 目标调整 → 跳转滴答目标页 |
| 当日能量概览 | 滴答计时数据 | 环形图 + 图例（专注时长分配） | 计时明细 → 跳转滴答时间统计 |

### 2. 时间与事件管理
| 子模块 | 数据来源 | 渲染方式 | 交互规则 |
|--------|----------|----------|----------|
| 今日事件概览 | 滴答当日任务 | 时间轴列表（标签色 + 打卡态） | 点击条目 → 跳转滴答对应条目；新建 → 跳转滴答 |
| 习惯 & 事件视图 | 滴答打卡 + 计时 | 周/月/年热力图 + 标签耗时占比 | 习惯维护 → 跳转滴答习惯页 |
| 时间视图 | 滴答计时 | 日/周/月分配看板（条形） | 计时调整 → 跳转滴答时间页 |

### 3. 灵感收集中枢
| 子模块 | 数据来源 | 渲染方式 | 交互规则 |
|--------|----------|----------|----------|
| 信息摄入概览 | Notion 信息摄入库 | 卡片（AI资讯/内容素材/投资信息）+ 导入框 | 导入 GitHub/小红书 → AI 提取关键词 + 重要等级；完整编辑 → 跳转 Notion |
| 灵光一现概览 | Notion 灵感库 | 卡片（标题/时间/状态/标签） | **自动化**：状态改为「脚本」→ 自动同步至项目进度-正在进行库 |
| 每日日记概览 | Notion 日记 | 日历（今日高亮/有日记圆点）+ 文本预览 | 撰写/编辑 → 跳转 Notion 日记模板 |

### 4. 自媒体项目进度
| 子模块 | 数据来源 | 渲染方式 | 交互规则 |
|--------|----------|----------|----------|
| 正在进行 | Notion 项目库 | 卡片（脚本及之后阶段预览） | 修改 → 跳转 Notion 项目库 |
| 发布复盘 | Notion 项目库 | 卡片（播放/点赞/收藏/评论预览） | 数据录入/复盘笔记编辑 → 跳转 Notion |

### 5. 学以致用
| 子模块 | 数据来源 | 渲染方式 | 交互规则 |
|--------|----------|----------|----------|
| 爆款拆解预览 | Notion 爆款拆解库 | 卡片（链接导入 + AI 拆解结果） | 完整笔记编辑 → 跳转 Notion 爆款拆解库 |
| AI 应用知识库预览 | Notion 知识库 | 卡片（知识点 + 实践案例摘要） | 点击 → 跳转对应 Notion 页面 |

## 四、视觉与交互规范

### 视觉规范
| 项 | 规范 |
|----|------|
| 整体风格 | 简约现代、高级质感、充足留白、多巴胺点缀色 |
| 双模式 | 浅色 / 深色（`data-theme` 切换，`localStorage` 持久化） |
| 配色（点缀） | 紫 `#7C5CFC`、粉 `#F06595`、珊瑚 `#FF6B6B`、青 `#12B886`、蓝 `#4DABF7`、黄 `#FCC419`（仅作点缀，不铺满） |
| 圆角 | 卡片 18px、小组件 12px |
| 阴影 | 轻量柔光 `0 6px 24px rgba(0,0,0,.06)`；弹层加重 |
| 字体 | 系统字体栈（PingFang SC / 微软雅黑 / Segoe UI） |

### 交互规范
| 场景 | 规则 |
|------|------|
| 导航 | PC 左侧常驻一级菜单；移动端自动收纳为汉堡菜单（侧栏滑出 + 遮罩） |
| 响应式 | 移动端简化组件（热力图降列、卡片单列）、适配单手操作；底部栏永显 |
| 跳转 | 所有编辑/新建/明细均跳转外部网页视图；工作台内不编辑长篇 |
| 录入 | 仅底部快捷栏支持单行灵感录入（自动同步 Notion） |
| 层级 | 最多 3 级（导航 1 级 + 页内分栏），无嵌套折叠菜单 |

## 五、AI 能力架构

### 5.1 内置长期复盘对话空间
- 独立对话空间，**持续聚合读取**：滴答时间记录、Notion 日记、灵感记录、项目复盘数据。
- 对话时自动注入「个人长期记忆上下文」，无需每次重复粘贴背景资料。
- 顶部展示已挂载的数据源 chips（📅滴答时间 / 📓日记 / ✨灵感 / 📊项目）。

### 5.2 每周自动工作流（调度）
```
每周固定时间（如周日 21:00）
  → 连接器汇总本周：滴答时间 + Notion 日记 + 灵感 + 项目复盘
  → AI 生成：个人状态复盘 + 自媒体优化建议
  → 复盘文档自动回写保存至 Notion（复盘库）
  → 持续更新 AI 长期记忆库（提炼为结构化长期上下文）
```

> 详见《跨平台自动化流转规则》与《每周 AI 复盘固定提示词》。

## 六、技术实现建议（落地路径）

| 模块 | 推荐方案 | 说明 |
|------|----------|------|
| 滴答连接器 | 滴答清单开放 API（OAuth） | 拉取任务/时间/习惯，**只读**为主；计时可由工作台发起回写 |
| Notion 连接器 | Notion API（Integration Token） | 拉取各数据库只读视图；灵感写入 / 状态同步为 **写操作（仅限灵感与自动化）** |
| 自动化调度 | WorkBuddy 定时任务 / n8n / Make | 监听 Notion webhook（状态变更）+ 每周 cron 工作流 |
| 工作台前端 | 静态前端（本原型 `index.html`） | 网关形态，无需自建 DB；配置 `LINKS` 映射即可上线 |
| 鉴权 | Token 存环境变量 / 密钥管理服务 | 不落前端、不落工作台数据库 |
| 刷新策略 | 看板轮询（30–60s）或 webhook 推送 | 保证概览「实时聚合」但只读 |

**上线最小步骤：**
1. 在 Notion / 滴答建立对应数据库（灵感库、日记、项目进度、信息摄入、爆款拆解、知识库）。
2. 配置连接器 Token 与 `LINKS` 跳转映射（填入真实 workspace ID）。
3. 部署本前端为只读网关；接好每周复盘 cron。
4. 验证「灵感→脚本→自动同步项目库」监听规则生效。

## 七（补）、v2 版本变更摘要

> 相对初版，本工作台已落地以下调整（详见《跳转链接点位清单》第八节）：

- **新增配置入口**：顶栏 ⚙️ 设置模态，录入 Notion Token / 数据库 ID / 滴答 Token，凭证存 `localStorage`。
- **清空 mock**：默认不展示任何假数据；未配置显示「前往配置」空状态。保留「示例数据」开关仅用于布局预览。
- **连接器落地**：`notionQuery / notionCreate / didaGet / didaComplete` 真实调用 API（可选填 CORS 代理解决浏览器跨域）。
- **时间模块重做**：今日事件支持单击完成、长按跳滴答计时；习惯热力图与标签占比均可点击跳转。
- **灵感中枢三 Tab**：信息摄入(Newsletter) / 灵光一现 / 日记，顶部切换；信息摄入新增小红书/GitHub 扒取 + AI 自动打标签并回写 Notion。
- **项目复盘详情页**：点击已发布卡片打开内容展示模态（数据条形 + 复盘笔记）。
- **学以致用反向同步**：爆款拆解支持一键回写 Notion 爆款拆解库。
- **计时改为跳转**：底部 ⏲️ 直接跳转滴答计时，移除内置倒计时弹窗及其常驻 bug。
